# Nami Japanese - Project Overview

## What is Nami Japanese?

Nami Japanese is a premium Japanese learning application designed to help beginners learn the Japanese writing system and basic vocabulary through interactive lessons, writing practice, quizzes, and progress tracking.

**Tagline:** Learn Japanese, One Stroke at a Time.

## Target Users

- Complete beginners learning Japanese
- Students preparing for JLPT N5
- Self-learners who want a structured approach
- Users interested in Japanese culture and language
- People who prefer visual and interactive learning

## Main Learning Goals

1. Master Hiragana (46 basic characters)
2. Master Katakana (46 basic characters)
3. Learn basic Japanese vocabulary
4. Practice writing characters with proper stroke order
5. Track learning progress and maintain study streaks
6. Build confidence for intermediate Japanese study

## MVP Scope

### Core Features (Phase 1)
- Onboarding experience
- Home dashboard with progress overview
- Hiragana lesson list and detail screens
- Katakana lesson list and detail screens
- Basic kana detail screen with character info
- Writing practice canvas (basic drawing)
- Flashcard screen for review
- Quiz screen for assessment
- Progress tracking screen
- Settings screen

### Data
- Static seed data for all 46 Hiragana characters
- Static seed data for all 46 Katakana characters
- Local progress storage with Room database
- User preferences with DataStore

## Future Scope

### Phase 2 Features
- Vocabulary lessons with audio pronunciation
- Advanced quiz types (listening, matching)
- Spaced repetition system (SRS) for flashcards
- Daily reminders and notifications
- Achievement badges and gamification

### Phase 3 Features
- JLPT N5-N3 preparation modules
- Advanced writing with stroke order validation
- AI-powered tutoring assistant
- Handwriting recognition using ML Kit
- Community features and leaderboards
- Cloud sync and backup

## Product Positioning

Nami Japanese positions itself as:
- **Premium quality** - Clean, polished UI comparable to Apple's design standards
- **Beginner-friendly** - Simple, guided learning path
- **Offline-first** - Works without internet connection
- **Privacy-focused** - All data stored locally by default
- **Focused** - Specializes in writing system mastery rather than trying to do everything

### Competitive Advantages
- Superior writing practice with canvas-based drawing
- Clean, distraction-free learning environment
- No ads, no subscriptions for core features
- Open-source foundation
- AI tutor integration planned for future

- Daily active users and retention
- Average session duration
- Writing practice frequency
